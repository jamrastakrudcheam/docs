# 41: ภ.ง.ด.1: ภาษีหัก ณ ที่จ่ายเงินเดือน (นำเข้าข้อมูลเงินเดือน)

**Status:** ready-for-agent
**Type:** task
**Blocked by:** [38 สถานประกอบการทางภาษีและทะเบียนภาษี (Tax register)](38-tax-registration-tax-register.md), [01 ตัดสินใจประเด็นออกแบบที่ค้าง](01-resolve-open-design-decisions.md), [36 บริการนำเข้าไฟล์กลาง (แบบ Oracle FBDI)](36-file-based-data-import.md)
**Spec:** [spec](../spec.md) · **มาตรฐาน:** [CODING_STANDARDS](../../../docs/CODING_STANDARDS.md)

## What to build

รุ่นแรกไม่มีโมดูลเงินเดือน จึงนำเข้าสรุปเงินเดือนรายพนักงานต่อเดือนจากระบบเงินเดือนภายนอก (เงินได้ตามมาตรา 40(1)/(2), ภาษีที่หัก) แล้วออก ภ.ง.ด.1 ใบแนบและใบสรุป ส่วนการลงบัญชีเงินเดือนให้ทำผ่าน Journal (category Payroll)

หน้าจอ: Tax: นำเข้าข้อมูลเงินเดือน, Tax: ภ.ง.ด.1
อ้างอิง: D14

## ขอบเขต

- แหล่งข้อมูลตาม P22: ระบบเงินเดือนภายนอกส่งออกตาม template PAYROLL_TAX_INTERFACE ของเรา
- นำเข้าผ่านบริการกลาง (ticket 36): import object `PAYROLL_TAX_INTERFACE` เทียบ Fusion ไม่มีใน Fusion Financials · หน่วยความสำเร็จ: ทั้งเดือน
- รูปแบบไฟล์นำเข้า (ตามผลตัดสินใจใน ticket 01), PayrollTaxLine ต่อพนักงานต่อเดือน
- ภ.ง.ด.1: ใบแนบรายพนักงาน (เลขประจำตัวผู้เสียภาษี, ชื่อ, เงินได้, ภาษี, เงื่อนไข) + ใบสรุป
- กระทบยอดภาษีเงินเดือนกับบัญชีภาษีหัก ณ ที่จ่ายค้างจ่ายใน GL ของเดือน
- ยืนยันยื่นพร้อม snapshot และฉบับยื่นเพิ่มเติม

## Acceptance criteria

- [ ] นำเข้าซ้ำเดือนเดิมแทนที่ข้อมูลเดิมได้เฉพาะก่อนยืนยันยื่น
- [ ] ยอดรวม ภ.ง.ด.1 ตรงกับไฟล์นำเข้า และแสดงผลต่างกับยอดใน GL
- [ ] ผู้ใช้ที่ไม่ใช่ Payroll officer ไม่เห็นข้อมูลรายพนักงาน

## เทสต์ที่ต้องมี

- [ ] e2e: นำเข้าไฟล์ถูก/ผิด, ซ้ำเดือน, สิทธิ์การเห็นข้อมูล, กระทบยอดกับ GL

- [ ] ไม่เก็บไฟล์นำเข้าเกินระยะที่กำหนด
