# 39: รายงานภาษีซื้อ ภาษีขาย และ ภ.พ.30

**Status:** ready-for-agent
**Type:** task
**Blocked by:** [38 สถานประกอบการทางภาษีและทะเบียนภาษี (Tax register)](38-tax-registration-tax-register.md), [04 ปฏิทินบัญชีและงวดของแต่ละโมดูล](04-fiscal-calendar-periods.md)
**Spec:** [spec](../spec.md) · **มาตรฐาน:** [CODING_STANDARDS](../../../docs/CODING_STANDARDS.md)

## What to build

ออกรายงานภาษีซื้อ/ขายรายเดือนต่อสถานประกอบการ และ ภ.พ.30 ที่สรุปจากสองรายงาน แสดงบนจอ ส่งออก Excel/PDF และยืนยันยื่นพร้อม snapshot (gl-process §9)

หน้าจอ: Tax: รายงานภาษีซื้อ, Tax: รายงานภาษีขาย, Tax: ภ.พ.30
อ้างอิง: D14, D15

## ขอบเขต

- กฎภาษีตามคำตอบใน [tax-review-p18-p21.md](../tax-review-p18-p21.md) (ตอบโดย Claude แทนทีมภาษี — ให้ผู้เชี่ยวชาญภาษีทบทวนก่อนยื่นแบบจริง)
- ภ.พ.30 แยกต่อสถานประกอบการเป็นค่าเริ่มต้น ยื่นรวมได้เมื่อนิติบุคคลตั้งค่าว่าได้รับอนุมัติ (P18) · ไม่มีแฟ้ม e-Filing รอบแรก (P23)
- หัวรายงาน: ชื่อผู้ประกอบการ, เลขผู้เสียภาษี, สถานประกอบการ (สำนักงานใหญ่/สาขาที่), เดือน/ปีภาษี
- บรรทัด: ลำดับ, วันที่และเลขที่ใบกำกับ, ชื่อคู่ค้า, เลขผู้เสียภาษี, สาขา, มูลค่า, ภาษี และยอดรวม
- ภ.พ.30: ยอดขาย (ต้องเสียภาษี/อัตรา 0/ยกเว้น), ภาษีขาย, ยอดซื้อที่มีสิทธิ์, ภาษีซื้อ, ภาษีต้องชำระหรือชำระเกิน, ชำระเกินยกมา
- ยืนยันยื่น: เก็บ snapshot + เลขฉบับ, แก้หลังยืนยันเป็นฉบับยื่นเพิ่มเติม
- วันกำหนดยื่นเป็นค่าตั้งค่า แสดงเตือนในหน้ารายงาน

## Acceptance criteria

- [ ] ยอดรวมรายงานภาษีซื้อ/ขาย = ผลรวม tax register ของเดือนและสถานประกอบการนั้น
- [ ] ภ.พ.30 คำนวณจากรายงานทั้งสองถูกต้อง รวมภาษีชำระเกินยกมาจากเดือนก่อน
- [ ] ICC/ITK และสาขาไม่ปนกัน ยกเว้นตั้งค่ายื่นรวม
- [ ] ยอดในไฟล์ Excel/PDF ตรงกับหน้าจอ
- [ ] ฉบับที่ยืนยันแล้วไม่เปลี่ยนเมื่อมีรายการใหม่ รายการใหม่ไปอยู่ในฉบับยื่นเพิ่มเติม

## เทสต์ที่ต้องมี

- [ ] e2e: ชุดข้อมูลสังเคราะห์หลายสาขา, ภาษีชำระเกินยกมา, ยื่นเพิ่มเติม, ส่งออกเทียบยอด

- [ ] ผ่าน `/code-review` ทั้ง Standards และ Spec
