# 01: ตัดสินใจประเด็นออกแบบที่ค้าง

**Status:** resolved
**Type:** decision
**Blocked by:** None (can start immediately)
**Spec:** [spec](../spec.md) · **มาตรฐาน:** [CODING_STANDARDS](../../../docs/CODING_STANDARDS.md)

## What to build

ปิดประเด็นที่พบตอนตรวจเอกสาร ก่อนเริ่ม ticket ที่พึ่งพามัน บันทึกผลเป็น ADR หรือแก้เอกสารออกแบบ แล้วเพิ่มคำศัพท์ใน GLOSSARY.md

อ้างอิง: P03, P08, P12

## ขอบเขต

- รหัสซ้ำ: ข้อตัดสินใจ P01–P12 ชนกับหน้าจอ PO P01–P06 ใน 02-screens.md เสนอเปลี่ยนรหัสหน้าจอเป็น PO01–PO06
- จังหวะรับรู้ COGS เมื่อ Customer Site ออกบิลหลัง POD (P03): ลง COGS ตอน Ship Confirm (03) จะไม่ match กับรายได้ เสนอบัญชีพัก "สินค้าส่งแล้วยังไม่ออกบิล"
- งวดปรับปรุง 13/14 (04) ยังไม่มีในข้อตัดสินใจ เสนอให้ตั้งค่าได้ 0–2 งวดต่อ Calendar
- path PDF Blueprint ใน README ชี้ไปที่เครื่องอื่น (ผู้ใช้ 99491) ให้นำไฟล์เข้า repo หรือระบุว่าเป็นแหล่งอ้างอิงภายนอก
- GL (gl-process §11): โครงสร้าง segment ผังบัญชี, วงเงินและ category ที่ต้องอนุมัติ Journal, ยื่น ภ.พ.30 แยกสาขาหรือรวม
- ภ.ง.ด.1: แหล่งข้อมูลเงินเดือนและรูปแบบไฟล์จากระบบเงินเดือนภายนอก
- ต้องการแฟ้มยื่นออนไลน์ (e-Filing / RD Prep) ในรอบแรกหรือไม่

## Answer

- ตัดสินตามข้อเสนอ (ผู้ใช้สั่งให้ดำเนินการ 26 ต.ค. 2026) บันทึกเป็น **P13–P25** ใน 01-scope-decisions.md · ADR-0005 (ผังบัญชีตั้งค่าได้ นำเข้าจาก EBS), ADR-0006 (Shipped-not-billed) · คำศัพท์ใน GLOSSARY.md
- P13 หน้าจอจัดซื้อ PO01–PO06 · P14 ผังบัญชีตั้งค่าได้แบบ Fusion ค่าจริงจาก Oracle EBS · P15 งวดปรับปรุง 0–2 (ค่าเริ่มต้น 13, 14) · P16 COGS ผ่าน Shipped-not-billed เมื่อออกบิลหลัง POD
- P17 Journal มือ/spreadsheet อนุมัติ ≥1 ขั้น ขั้น 2 ตามวงเงิน · P18 ภ.พ.30 แยกสถานประกอบการ · P19 tax point ตั้งต่อ tax code (บริการ = payment) · P20 recovery rate · P21 WHT ตอนจ่าย, กรมสรรพากรเป็นผู้ขายประเภทหน่วยงานภาษี
- P22 ภ.ง.ด.1 นำเข้าจาก PAYROLL_TAX_INTERFACE · P23 e-Filing นอกรอบแรก · P24 ย้ายข้อมูล EBS เป็น ticket 43 · P25 PDF Blueprint เป็นแหล่งอ้างอิงภายนอก
- ประเด็นภาษี P18–P21: ผู้ใช้อนุญาตให้ Claude ตอบแทนทีมภาษีใน [tax-review-p18-p21.md](../tax-review-p18-p21.md) — P19 แก้เป็นภาษีขายสินค้าเกิดเดือนที่ส่งมอบ · พบช่องว่าง ภ.พ.36/ภ.ง.ด.54 → ticket 44 · ยังไม่มีผู้เชี่ยวชาญภาษีลงนาม
